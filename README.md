# userscripts

My personal userscripts, managed with [Violentmonkey](https://violentmonkey.github.io).

## anilist.co

| Script                                   | Description                                                                |
| ---------------------------------------- | -------------------------------------------------------------------------- |
| [`autoload.user.js`][anilist-autoload]   | Adds a button to the user's profile that pages through the activity feed   |
| [`dashboard.user.js`][anilist-dashboard] | Updates the home dashboard to load the complete "In Progress" list preview |
| [`favorites.user.js`][anilist-favorites] | Overrides the reorder button to load all favorites and sort them by title  |

## monarch.com

| Script                                               | Description                                                             |
| ---------------------------------------------------- | ----------------------------------------------------------------------- |
| [`connected-tools.user.js`][monarch-connected-tools] | Hides revoked entries from connected tools in the integrations settings |

## nyaa.si

| Script                          | Description                                                             |
| ------------------------------- | ----------------------------------------------------------------------- |
| [`search.user.js`][nyaa-search] | Adds a wider search bar and support for date filtering with auto-paging |
